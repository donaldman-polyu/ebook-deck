Slide 06 Technical Specs

Developer Architecture Guidelines

Frontend Stack: React / Tailwind / HTML5 Canvas Reader

1. State & URL Synchronization

Active search terms, applied category filters, and active view modes (Grid vs. List) must bind directly to URL query params (e.g. ?genre=fiction&view=grid) for shareable deep links.

2. Responsive Breakpoints

The left library filter column must collapse into a mobile slide-out drawer below 768px. The e-reader canvas must switch automatically from 2-column spread to single-column vertical scroll on mobile viewports.

3. Image Lazy-Loading

All book cover images and author avatar thumbnails must utilize lazy loading and WebP formats to guarantee instant initial page loads during infinite scrolling.
